## 4. Software Infrastructure Verification (Delivery Chain)

The complete delivery chain has been verified and functions without software bugs:
1. **Database Schema**: `ProductImage` model correctly references `Product` with `image = FileField(upload_to="products/%Y/%m/")` or `uuid`, `is_hero=BooleanField`, `sort_order=PositiveIntegerField`.
2. **Filesystem**: File exists at `MEDIA_ROOT/products/<uuid>/hero.jpg`.
3. **Django URL Generation**: Handled via `request.build_absolute_uri()` or relative `/media/products/...`.
4. **API Serialization**:
   - `ProductListSerializer.hero_image`: Returns full media URI.
   - `ProductDetailSerializer.hero_image`: Restored in Step 3, returns full media URI.
   - `ProductDetailSerializer.images`: Returns gallery image list with URLs.
5. **Next.js Routing & Rewrites**:
   - `frontend/next.config.js` maps `/media/:path*` to `${backend}/media/:path*`.
   - `images.remotePatterns` allows `127.0.0.1:8000`, `localhost:8000`, and `https://**`.
6. **Frontend UI Fallback**:
   - If an image is missing or cannot load, `ProductCard.jsx` and `app/products/[slug]/page.js` render an authentic Western Ghats seal badge fallback (`100% Authentic Estate Spice`) rather than a broken image icon.
